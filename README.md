# Declare Variable — Valid Identifier

Mini-exercice JavaScript sur la déclaration correcte d’une variable.

## Objectif pédagogique

Comprendre :

- la syntaxe `let` ;
- la création d’un identifiant valide ;
- l’affectation d’une chaîne de caractères à une variable.

## Exemple

```js
let site_web = "Udemy";
```

Le nom `site_web` utilise un underscore et constitue un identifiant valide en JavaScript.

## Fichier principal

`index.js`

## Exécution

```bash
node index.js
```
